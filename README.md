# Trackified Homebrew tap

```sh
brew install trackified/tap/trackified
```

Formulae here are generated by GoReleaser from [trackified/trackified-cli](https://github.com/trackified/trackified-cli) releases. Do not edit them by hand.

## How it updates

`update-formula.yml` runs hourly here, reads the latest
[trackified-cli](https://github.com/trackified/trackified-cli) release, verifies every archive's
GitHub build provenance (`gh attestation verify`) and its checksum, then writes
`Formula/trackified.rb`. The CLI repo holds no credential for this tap.
